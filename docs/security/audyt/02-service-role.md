## O czym jest ten plik

`createAdminClient()` łączy się rolą `service_role`, dla której Postgres **nie stosuje**
polityk RLS. Baza nie chroni tu już niczego — izolacja zależy wyłącznie od kodu.

Właściwe pytanie nie brzmi „czy jest filtr", tylko **skąd pochodzi jego wartość**.
Filtr wypełniony identyfikatorem z ciasteczka wygląda identycznie jak bezpieczny.
